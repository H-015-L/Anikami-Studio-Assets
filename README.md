# Anikami Studio Assets

Public dependency assets for Anikami Studio.

## Purpose

This repository provides versioned dependency manifests for Anikami Studio.
Python wheel files are distributed through GitHub Releases and are not stored
in the Git history.

## Current baseline

- Anikami Studio: 1.2.1
- Python: 3.10.11
- Platform: Windows x64
- Accelerator: CUDA 12.4
- Wheel count: 117

## Repository structure

- `manifests/` — dependency manifests
- GitHub Releases — binary wheel assets

Third-party packages retain their respective upstream licenses and terms.
